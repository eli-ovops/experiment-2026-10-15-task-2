## 0. 背景（来自官方/媒体报道，2026-10-08）
- WorkBuddy 新上线「独立文件浏览器」：本地文件右键 →「打开方式」→ WorkBuddy，左边文件、右边 Buddy 对话。
- 支持 Word / Excel / PPT / PDF / Markdown / HTML / 图片；支持多标签页，每个文件独立对话。
- 可让 Buddy 基于 Excel 生成网页版汇报，**新文件默认保存在原文件所在目录**。
- Excel 可直接编辑，按保存按钮或快捷键存回原文件；外部改过同一文件时会提示刷新或另存副本，不会自动覆盖。
- 无需单独下载，更新 WorkBuddy 即可用。
- 积分：查看、编辑本地文件不耗积分；调用 AI 总结/改写/生成时按实际任务消耗积分。
- 隐私：只读取用户主动打开或添加的文件，不扫描磁盘。
- 报道**未写明**：具体版本号、macOS 系统要求、积分单价/套餐 → 以下由实测补充。

## 2. 测试数据
- 文件：`销售数据_示例.xlsx`（已生成，放到桌面新建文件夹 `周报测试/` 内）。
- 结构：40 行，列 = 日期、区域、产品、销售员、销量、销售额(元)。
- 上周 = 2026-10-05~10-09，本周 = 2026-10-12~10-16；4 个区域 × 5 个产品 × 2 周。

### 预埋答案（仅用于核对，不要告诉 AI）
| 区域 | 上周销售额 | 本周销售额 | 变化 | 环比 |
|---|---|---|---|---|
| 华东 | 56,185 | 59,979 | +3,794 | +6.8% |
| 华南 | 50,197 | 52,292 | +2,095 | +4.2% |
| **华北** | **45,305** | **25,844** | **−19,461** | **−43.0%** |
| 西南 | 31,932 | 33,528 | +1,596 | +5.0% |
| 合计 | 183,619 | 171,643 | −11,976 | −6.5% |

正确结论：**华北下滑最大，本周 25,844 元，比上周少 19,461 元，环比 −43.0%**；其余三区均小幅增长；整体 −6.5%。

## 3. 测试步骤（全程录屏）
1. Finder 进入 `周报测试/`，右键 `销售数据_示例.xlsx` → 打开方式 → WorkBuddy。开始计时 T0。
2. 在右侧 Buddy 输入（一字不改）：
   `分析各区域本周销售，找出下滑最大的区域`
   记录完成时间 T1、回答全文截图。
3. 接着输入：
   `做成网页版周报，老板手机能看`
   记录完成时间 T2；确认 HTML 文件是否出现在 `周报测试/` 原目录，记录文件名。
4. 在 WorkBuddy 内打开生成的 HTML 预览；再用 Chrome 开发者工具手机模式（iPhone 尺寸）打开，检查手机适配。
5. 可选：通过微信「文件传输助手」发到手机，用 WorkBuddy 小程序打开预览（录手机屏）。
6. 记录测试后积分余额，计算消耗。
7. 若 AI 理解“本周”有歧义（比如没按日期分周），**不要换提示词重来掩盖**：先如实记录，再追加一次澄清提示（如“上周=10/5-10/9，本周=10/12-10/16”）并单独记录。
